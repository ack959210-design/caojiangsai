# 研写 Lab · 考研英语小作文训练营

中文考研英语应用文学习工具，围绕具体内容 A → 原因或影响 B → 交际功能 C 组织训练。从使用模板逐步过渡到独立表达，包含中英对照、约100词范文、审题、互动填空、规则自查、学习记录与教师班级。
