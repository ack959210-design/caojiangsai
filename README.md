# 研写 Lab 免费教学预览

中文考研英语应用文学习工具，围绕具体内容 A、原因或影响 B、交际功能 C 组织训练。

本仓库入口是完全内联的静态预览。学习首页和前两节基础课免费，包含讲解、例句、互动应用与复习测试。其余课程及完整训练显示预览提示。本地设置和已经保存的个人作文可查看、导出。

当前仓库的免费静态预览不接收付款，不提供账户、班级或 AI 后端，也不会显示虚构的付款成功或试用状态。仓库上传和 GitHub Pages 发布是两步；本文不表示已经部署上线。启用 Pages 并确认构建成功后，才能提供实际网站地址。

## 完整 MIT 源码

[下载完整源码包](./yanxie-lab-source.zip)。源码包包含 60 个已审核的项目文件，含教材、Node.js 服务端、前端、测试和部署说明，按 MIT 许可公开；许可全文见 [LICENSE](./LICENSE)。

源码包不含个人收款码、真实 API 密钥、数据库、已创建的账户、会话数据或临时文件。

## 解压与运行

1. 安装 Node.js 24.2 或更新版本。
2. 解压 yanxie-lab-source.zip，进入包含 server.mjs 的项目目录。
3. 运行 node server.mjs，然后打开 http://127.0.0.1:4173。
4. 如需管理员，在终端运行 node server.mjs --create-admin 你的邮箱 管理员显示名，按提示输入密码。不要把密码放进命令参数。
5. 管理员通过设置界面上传自己的微信或支付宝收款码、配置联系说明，并邀请教师。详细步骤见源码包内 README-server.md 和 README-subscription.md。

项目使用 Node.js 内置模块，无需安装第三方服务端依赖。测试可按包内 README.md 的命令运行。修改教材后运行 node build-access.mjs 重建免费目录与完整教材。

## 另行部署的账户服务

完整账户版必须另外部署到支持 Node.js、HTTPS 和持久化磁盘的主机。GitHub Pages 不能运行 Node.js 与 SQLite，因此这个免费入口不提供收费账户功能。

账户版学生注册后可连续体验 72 小时，由服务器账户创建时间起算；随后以 10 元购买 30 天训练服务，非自动扣款。扫码转账后由管理员核对实际到账才开通；学生提交付款说明不会自行获得权限。到期仍可查看和备份本人作文。教师与管理员免学生订阅门禁。

未配置收款码时不能创建订单。公开源码没有 OpenAI 密钥，AI 需另行在服务端配置；真实付费模型调用尚未验证。

开源代码可自行运行、修改与复制。订阅限制部署实例提供的课程接口和账户服务，不是 DRM，不能阻止提取源码或保存已取得的教材；此前交付的离线教材也不会被追溯加上到期锁。
